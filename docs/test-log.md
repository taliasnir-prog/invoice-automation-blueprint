## מה התגלה ותוקן

**ריצה 1, שתי תקלות:**
- שמות השדות של Gmail היו שונים ממה שהנחתי. השדות האמיתיים הם `fromName`, `fromEmail`, `internalDate` ו-`fullTextBody`. תוקן בכל המודולים.
- כשהחיפוש בגיליון לא מצא כלום, ה-Aggregator החזיר רשימה עם פריט ריק אחד (`[{"key":null}]`) ולא רשימה ריקה. התנאי "אורך הרשימה = 0" חסם את Claude. הוחלף בתנאי שבודק שהמפתח עצמו לא נמצא ברשימה (`array:notcontain`).

**אחרי ריצה 2:** הנוסחה בלשונית Keys הפנתה ל-`A2:A`. כש-Make הוסיף שורה ל-Inbox, Google הזיז את ההפניה ל-`A3:A`, ו-Keys הפסיקה לראות את המפתח. זה נתפס לפני הבדיקה הבאה. הוחלף בעמודות שלמות.

**ריצה 4, T6:** Claude החזיר את הנתונים הנכונים ולא ביצע את ההוראה המוזרקת. אבל הוא לא עשה escape למירכאות ב"בע"מ", וה-JSON נכשל בפענוח (`Source is not valid JSON`). המייל נכנס ל-Needs Review, כמו שצריך. התיקון: ההוראה ל-Claude דורשת עכשיו JSON תקין בלבד, עם escape למירכאות, ללוכסן הפוך ולירידת שורה, ועם דוגמה של בע"מ. לא הוספתי תיקון אוטומטי של הפלט. אחר כך מחקתי רק את שורת T6, אחרי שאימתתי לפי המפתח שזו השורה הנכונה, והרצתי שוב.
